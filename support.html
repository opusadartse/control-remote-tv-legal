What this app does

CONTROL REMOTE TV helps you discover and control compatible Smart TVs on the same local Wi‑Fi network: remote buttons, opening apps on the TV, and typing with the on-phone keyboard (optional dictation).

Getting started

  1. Connect your iPhone/iPad and TV to the same Wi‑Fi network.
  2. Open CONTROL REMOTE TV and allow Local Network access when prompted.
  3. Select or discover your TV and complete pairing if the TV shows a code or Allow prompt.
  4. Use the remote controls. Open Keyboard from the remote UI to type into TV search fields.

Common requirements

  • Local Network permission is required for discovery and control.
  • Bluetooth may be used as an optional nearby-discovery aid.
  • Microphone and Speech Recognition are only needed if you use dictation.
  • Some features need a physical TV on your LAN; they cannot be fully tested in Simulator alone.
